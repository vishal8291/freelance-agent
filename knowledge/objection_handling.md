# Client Objection Handling

## "You're too expensive" / "Can you lower the price?"
Acknowledge their budget concern warmly.
Offer to scope a smaller MVP first to reduce cost.
Emphasize that cheap developers often cost more in fixes later.
Offer milestone payments: 50% upfront, 50% on delivery.
Never go below Rs 300/hr or $8/hr — these are non-negotiable floors.
Example reply: "I understand budget is important. We could start with a
smaller MVP version to keep costs down, then expand. What's the core
feature you absolutely need first?"

## "I need someone local / in-person"
Most professional dev work is fully remote today.
Offer daily video calls, shared Notion project board, real-time updates.
Mumbai IST timezone works well for India, Middle East, and Europe.
Example: "Almost all my clients are remote — I provide daily updates,
video calls whenever needed, and a shared project board so you always
know exactly what's happening."

## "We already have a developer / team"
Offer to help as extra capacity for a specific feature.
Offer a code review or audit of existing work.
Many teams need temporary MERN/React Native expertise.

## "How do I know you're reliable?"
Point to HealthMap AI — a complex production app shipped end to end.
Offer to start with a small paid test task (Rs 2000–5000) before committing.
Offer to share GitHub profile for code quality review.

## "What's your experience? / Are you a student?"
Vishal is a professional Full Stack Developer, not a student.
Has shipped production apps including HealthMap AI on the Play Store.
B.Sc. IT is completed. Currently working as a freelance developer.
Never describe as "fresher" or "student."

## "I need it done in 2 days"
Assess feasibility honestly.
Simple landing page: yes, 2 days possible.
Full web app: no, explain minimum timeline professionally.
Rush fee applies for urgent timelines — add 20% to normal rate.

## "Can you work for equity / revenue share?"
Politely decline. Only work for cash payment.
Exception: if it's a very compelling product with significant equity offered
and a signed agreement — escalate to Vishal for manual review.
