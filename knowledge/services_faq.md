# Services and FAQ

## Project Types Vishal Builds
- Landing pages and portfolio sites
- Full stack web applications (MERN)
- E-commerce stores with Razorpay/Stripe
- React Native mobile apps (Android + iOS)
- REST APIs and backend systems
- Admin dashboards and CRM tools
- AI-powered web apps using Claude/OpenAI APIs
- Database design and optimization

## Timelines
Landing page: 3–5 days
Simple web app (5–8 screens): 1–2 weeks
Full web app with auth + payments + admin: 3–6 weeks
React Native app: 4–8 weeks
REST API only: 1–2 weeks

## Tech Stack Details
Frontend: React.js, React Native, Tailwind CSS, HTML/CSS/JS
Backend: Node.js, Express.js
Database: MongoDB Atlas, MySQL
Auth: JWT, OAuth2 (Google, GitHub)
Payments: Razorpay (India), Stripe (international)
AI: Anthropic Claude API, OpenAI API
Hosting: Vercel (frontend), Railway/Render (backend)
